# Support

## Before asking for help

1. Read the [Installation](README.md#installation) and [Troubleshooting](README.md#troubleshooting) sections of the README.
2. Search the [existing issues](https://github.com/choudharyjayesh668/QuickQuit/issues?q=is%3Aissue), including closed ones.

## Where to go

| I want to | Go to |
| --- | --- |
| Report a reproducible bug | [Bug report](https://github.com/choudharyjayesh668/QuickQuit/issues/new?template=bug_report.yml) |
| Suggest an improvement | [Feature request](https://github.com/choudharyjayesh668/QuickQuit/issues/new?template=feature_request.yml) |
| Ask a question about installing or using QuickQuit | [Open an issue](https://github.com/choudharyjayesh668/QuickQuit/issues/new/choose) and choose **Open a blank issue** |
| Report a security vulnerability | [SECURITY.md](SECURITY.md). Do not use a public issue |
| Report a conduct problem | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md#enforcement) |
| Contribute code or documentation | [CONTRIBUTING.md](CONTRIBUTING.md) |

## What to include

- Your macOS version (`sw_vers`) and Swift version (`swift --version`).
- The QuickQuit version: `defaults read /Applications/QuickQuit.app/Contents/Info CFBundleShortVersionString`.
- What you expected, what happened, and the exact text of any error message.

Do not include passwords, personal documents, or other sensitive information.

## Response times

QuickQuit is maintained by one volunteer and comes with no guaranteed response time. Clear, complete reports get answered faster.
